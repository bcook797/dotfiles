# Personal working agreements

- Read repository instructions and existing implementation before proposing or making changes.
- Preserve unrelated user changes and work safely in a dirty worktree.
- Prefer focused, reversible changes that follow the repository's established conventions.
- Verify changes with the most relevant available tests, checks, or diagnostics.
- Ask before destructive operations or actions that affect external systems, accounts, or people.
- Never commit credentials, authentication state, secrets, or private machine data.
- Clearly report assumptions, incomplete verification, and any remaining manual steps.
